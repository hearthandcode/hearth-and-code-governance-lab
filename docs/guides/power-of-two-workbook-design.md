# Power-of-Two Worksheet and Workbook Design

Status: candidate authoring procedure. The scaling rule organizes thought; it does not justify padding.

## Four dimensions

Every worksheet is designed across subject, response, governance, and projection. Subject defines the bounded matter. Response selects exact input semantics. Governance binds source, privacy, review, and effects. Projection selects the smallest readable summary.

## Eight question scales

| Count | Best use | Split condition |
|---:|---|---|
| 1 | one consequential prompt | a second independent decision appears |
| 2 | binary comparison across two distinct lenses | either lens needs internal decomposition |
| 4 | compact orientation | cross-functional review appears |
| 8 | standard bounded review | more than one human gate is present |
| 16 | release or architecture review | sections lose one coherent purpose |
| 32 | exhaustive catalog evaluation | completion burden impairs judgment |
| 64 | exceptional audit | use multiple worksheets unless atomicity is essential |
| 128 | workbook-level maximum | always distribute across explicit worksheets |

## Sixteen construction checks

1. One sentence states the decision-changing purpose.
2. Every question belongs to one declared subject domain.
3. Every question uses the narrowest honest interaction kind.
4. Labels do not carry semantics that IDs omit.
5. Required and optional questions are distinguished deliberately.
6. A matrix row retains state independently.
7. Ranked choice includes the complete reorderable set.
8. Repeatable groups cap items and validate every field.
9. Privacy matches the most sensitive expected answer.
10. Authority references are explicit and bounded.
11. Review and verification remain distinct.
12. Visualizations retain a text or table equivalent.
13. Unknown fields, kinds, and versions fail visibly.
14. Prepared packets preserve held effects.
15. Validation evidence names the command and result.
16. The handoff asks for one bounded human disposition.

## Workbook composition

A workbook should contain two, four, or eight worksheets with distinct purposes. A strong four-part default is orientation, evidence, disposition, and acceptance. An eight-part program may add constraints, alternatives, risks, and downstream routing. Sequential navigation is appropriate only when later worksheets depend on prior answers; otherwise use free navigation.

Do not make a single worksheet imitate a workbook. Split when there are multiple human gates, privacy boundaries, source authorities, or downstream owners.
