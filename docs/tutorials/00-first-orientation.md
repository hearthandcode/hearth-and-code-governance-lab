# Lesson 1: First orientation

## Goal

Understand the four layers before creating content: source, projection, response, and authority.

## Step-by-step

1. Open a Markdown note containing an HCC YAML fence.
2. Read the plain prose and YAML without relying on the plugin.
3. Switch to Reading view. The plugin turns valid YAML into a semantic widget.
4. Switch to Live Preview and place the cursor inside the fence. The YAML returns for editing.
5. Move the cursor outside the fence. The widget returns.
6. Enter a temporary answer. Notice that the note source does not change.
7. Reload or disable the plugin only after understanding that unsaved answers live in memory.
8. Locate the worksheet's final-review and response-packet controls, but do not create a packet unless that write is authorized.

## Four-layer model

| Layer | Example | Authority |
|---|---|---|
| Source | Markdown prose and YAML fence | editable authored record |
| Projection | rendered form, table, chart, or dashboard | derived view only |
| Response | in-memory answer or immutable packet candidate | intake evidence only |
| Authority | human review, verification, canonical decision | separate governed action |

## Verify

- Invalid YAML remains visible with diagnostics.
- Valid widgets retain understandable source when rendering is unavailable.
- Entering an answer does not silently rewrite the note.
- A copied or created packet does not become reviewed or canonical automatically.
