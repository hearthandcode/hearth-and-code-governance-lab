# Hearth and Code Governance Lab tutorials

This directory is the progressive learning route for people and agents. Complete only the lessons relevant to the task. Every example remains source-visible Markdown/YAML, and every write or external effect retains its separate gate.

## Eight-lesson route

| Lesson | Outcome | Typical time |
|---:|---|---:|
| 1 | [Orient to source, projection, response, and authority](00-first-orientation.md) | 10 minutes |
| 2 | [Install or inspect the correct identity and verify the host](01-install-and-verify.md) | 15 minutes |
| 3 | [Create a first interaction and worksheet](02-first-form.md) | 20 minutes |
| 4 | [Compose worksheets into a workbook](03-workbooks.md) | 20 minutes |
| 5 | [Create, reload, and amend immutable response packets](04-response-packets.md) | 25 minutes |
| 6 | [Add accessible views and style them](05-views-and-styling.md) | 20 minutes |
| 7 | [Use governance, studio, and exchange surfaces](06-governance-studio-exchange.md) | 30 minutes |
| 8 | [Operate from an agent and recover safely](07-agent-operations-and-recovery.md) | 20 minutes |

The sequence is educational, not an authority chain. Lesson 5 requires an already authorized response provider. Lesson 7 prepares proposals and manual exchange only. None authorizes installation, canonical write-back, a provider call, Git, publication, release, or Community submission.

## Two operating contexts

In a source checkout, start at root `llms.txt`. Use `hearthandcode-governance-obsidian` for Hub-to-Obsidian orchestration and one of the four narrower packages under `skills/` for detailed authoring, workbook, response, or governance work. Validate with repository commands. In an installed Obsidian vault, inspect only the expected plugin manifest and explicitly named notes. Do not install dependencies or enumerate response packets in the vault.

## Completion standard

For each completed lesson, retain the source path, plugin and contract versions, direct validation result, visible defects, held effects, and one next human action. A successful tutorial is evidence of the exercised route only, not blanket release readiness.
