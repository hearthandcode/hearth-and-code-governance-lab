# Governance Lab Guided Vault

This disposable vault is the minimal public learning surface for Hearth and Code Governance Lab.

Open **00 Start Here.md** and follow the eight-stage tour. The vault contains:

- one start page;
- eight guided lessons;
- one explicit workbook;
- four practice worksheets;
- the plugin-owned `Intake/HCC Responses/` folder only after you explicitly create a packet.

The repository's private development vault contains a much larger evaluation corpus. That history is intentionally excluded from the public projection so a new user sees the product workflow rather than its construction process.

The plugin does not call an AI model, scan the vault, update frontmatter, overwrite packets, or write into a canonical knowledge system. Use synthetic or non-sensitive data until you have reviewed the privacy, response-packet, and downstream-integration boundaries.
