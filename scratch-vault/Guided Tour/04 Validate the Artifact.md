# 4. Validate the Artifact

When the agent writes into an authorized Hub route, open that exact note in the Hub's Obsidian vault; do not make a duplicate paste-only copy. If the agent returned a proposal without write authority, create or paste it only after choosing the destination yourself. In Reading view or Live Preview, confirm that each fence renders. Use the command palette action **Validate active worksheet contract**.

Before the note is created or renamed, the agent should have run the Hub path proposer and validator required by the active Hub charter. After authoring, it should report the grammar checks it actually ran. Obsidian provides the final host-rendering check; neither path validation nor rendering establishes truth or approval.

A diagnostic should identify a code and YAML path while leaving the source available. Fix only the reported defect, validate again, and confirm that the repair did not change the intended meaning.

Structural validity does not prove factual accuracy, good question design, consent, review, or authority.
