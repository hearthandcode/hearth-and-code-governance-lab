# 2. Configure the Plugin

Open **Settings → Hearth and Code Governance Lab**. Changes should apply immediately to open rendered notes.

- Use **Focused intake** and **One question at a time** for deliberate answering.
- Use **Guided worksheet** for a visible progress and navigation surface.
- Use **Analysis workbench** for denser questions and projections.
- Use **Audit and governance** when source, contracts, and evidence need to remain prominent.

Presentation preferences may change visibility, spacing, labels, and navigation. They cannot change answers, packet lineage, source Markdown, privacy, persistence policy, or authority.
