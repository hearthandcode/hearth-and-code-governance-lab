# 5. Complete a Worksheet

Open [[Worksheets/01 Guided Orientation]]. Answer each required question, use correction/context when useful, and inspect the response proposal. Try one-question presentation and the floating Previous/Next controls.

Responses remain in plugin memory until you explicitly create a packet. Reloading or disabling the plugin can discard an unsaved draft.
