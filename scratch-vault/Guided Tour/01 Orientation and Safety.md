# 1. Orientation and Safety

Governance Lab turns source-visible YAML fences into interactive companion views. Markdown remains inspectable. A rendered widget is a projection, an answer is a draft, and a saved response packet is immutable candidate evidence.

Use four boundaries:

1. name the exact purpose and sources;
2. classify privacy before disclosure;
3. keep model output as a proposal;
4. require a separate gate for canonical writes.
