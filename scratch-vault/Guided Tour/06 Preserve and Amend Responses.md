# 6. Preserve and Amend Responses

For the normal create route:

1. answer the worksheet;
2. optionally review, prepare, or copy its final YAML;
3. choose **Create immutable packet**;
4. inspect the exact path and digest shown beside the toolbar;
5. choose **Confirm and create packet**;
6. paste the automatically copied locator into the agent conversation only when you want downstream review;
7. use **Load or amend packet** only for an explicit digest-verified reload or successor; and
8. create every correction as a new packet without modifying its predecessor.

Use [[Worksheets/03 Response Lifecycle Practice]] as the checklist. Packets are created only under `Intake/HCC Responses/` in this vault. The agent must receive the exact locator from you; it must not search for packets.
