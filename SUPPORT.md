# Support Posture

Hearth and Code Governance Lab is a prerelease with best-effort maintenance and no response-time promise. The synthetic scratch vault remains the supported evaluation environment until real-host release evidence is admitted.

The initial maintainer is `fractalis` on behalf of Hearth & Code. Releases are readiness-driven rather than scheduled. The first public candidate declares Obsidian 1.13.4 desktop as its minimum because that exact host passed the clean-vault canary. Other desktop operating systems remain unclaimed pending direct evidence; Android and iOS/iPadOS are unsupported. When reporting an issue:

- reproduce issues in the scratch vault;
- include plugin version, Obsidian version, view mode, operating system, fixture path, and diagnostic text;
- remove private or sensitive content;
- do not assume candidate grammar or response packets will migrate automatically.

Structured bug and feature templates are now prepared for a future public repository, but no public issue tracker or response expectation exists yet. The [first-use and manual-install guide](docs/guides/first-use-and-manual-install.md) defines the current disposable-vault evidence route.

The disposable test vault intentionally installs `hcc-widget-lab` under the compatibility display name **Hearth & Code Governed Widgets**. A clean public candidate uses `hearth-and-code-governance-lab` and **Hearth and Code Governance Lab**. Reload or restart Obsidian after a build and confirm which vault and plugin directory are active.
